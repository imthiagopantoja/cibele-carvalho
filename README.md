# Cibele Carvalho

Site institucional de Cibele Carvalho, recriado a partir da versão pública original.

## Visualização local

Sirva a pasta `dist` com qualquer servidor HTTP estático.

## Estrutura

- `dist/index.html`: página principal
- `dist/style.css`: identidade visual e responsividade
- `dist/app.js`: animações e interação dos cartões
- `dist/assets/`: imagens e marca

O monograma circular flutuante foi removido da área da fotografia em todos os tamanhos de tela.
